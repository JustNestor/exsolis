# GLTF Pipeline — Golden / Oracle Testing Plan

**Goal**: Catch every class of regression (exploded mesh, missing arms, mirrored body, wrong animation, UV corruption, index/vertex mismatch) with automated, data-driven tests that compare against a known-good oracle.

---

## 1. Test Architecture

| Layer | What it validates | Oracle source |
|-------|-------------------|---------------|
| **Unit (CPU)** | Parsing, rig building, clip decoding, arm cut, bone palette composition | Serialized expected structs (`.ron`/`.json`) committed alongside test assets |
| **Integration (CPU→GPU)** | Upload data layout, index rewriting, allocation offsets, draw call parameters | Round-trip: upload → read back → compare |
| **Render (GPU)** | Final pixel output, skinning correctness, viewmodel placement, mirroring | Reference screenshots (PNG) + per-frame metric hashes |

All tests live in `client/src/gltf.rs`, `client/src/anim/rig.rs`, `client/src/anim.rs` as `#[test]` functions so they run in `cargo test`.

---

## 2. Failure Taxonomy & Detection Points

| # | Symptom | Root cause | Where to catch |
|---|---------|------------|----------------|
| 1 | Exploded / needle triangles | `T(-pivot)` in model matrix applied before skinning | Unit: `posed_arms_move_as_one_body`; Render: vertex drift metric |
| 2 | Index/vertex mismatch (garbage geometry) | `first_index` / `vertex_offset` double-count or wrong allocation | Unit: `draw_call_offsets_match_upload`; Integration: read-back |
| 3 | Viewmodel shows full body | Arm cut too permissive or body instance not stripped | Unit: `the_arm_cut_includes_the_hand_geometry`; Integration: instance count check |
| 4 | Viewmodel mirrored | Wrong `MODEL_YAW_OFFSET` sign or front-face culling | Render: screenshot hash |
| 5 | Arms detached from shoulders | Arm cut missing hand joints (`spLeft_963`, `RightHand_1006`) | Unit: `the_arm_cut_includes_the_hand_geometry` |
| 6 | Animation 4× too fast | `playback_rate` missing scale division | Unit: `playback_rate_scales_with_scale` |
| 7 | Clip roles wrong | Manifest keyed to wrong model path | Unit: `girl_clips_decode_with_the_measured_shapes` |
| 8 | UV corruption / blurry | Tangent generation missing / wrong handedness | Unit: `tangent_handedness_matches_reference` |
| 9 | Non-LINEAR interpolation dropped | `decode_clips` skips STEP/CUBICSPLINE | Unit: `interpolation_modes_preserved` |
| 10 | Morph targets / multi-UV ignored | Loader doesn't read `TEXCOORD_1` or `MORPH_*` | Unit: `second_uv_set_loaded` |
| 11 | Skinning weighted vs rigid mismatch | `GltfGpuVertex` has 1 joint vs 4-weight blend | Unit: `weighted_skinning_roundtrip` |
| 12 | Joint index out of bounds | Palette stride 256 but skeleton has >255 joints | Unit: `joint_index_bounds_check` |

## 4. Test Suite Specification

### 4.1 Unit Tests (CPU only, no GPU)

| Test function | File | Validates |
|---------------|------|-----------|
| `decode_duck_glb` | `gltf.rs` | Basic parse roundtrip |
| `converted_models_loader_faithful` | `gltf.rs` | Texture normalization, material indices, UV bounds |
| `gltf_gpu_material_layout` | `gltf.rs` | CPU/GPU material struct layout match |
| `girl_rig_bakes_the_hierarchy_into_a_handful_of_draws` | `rig.rs` | Rig building, joint count, primitive merge |
| `the_rest_pose_palette_is_the_identity` | `rig.rs` | Rest pose palette = identity |
| `the_baked_geometry_stays_inside_the_original_bounds` | `rig.rs` | No vertex explosion at rest |
| `a_walk_pose_keeps_the_figure_together` | `rig.rs` | Walk clip doesn't explode mesh |
| `the_arm_cut_includes_the_hand_geometry` | `rig.rs` | Arm cut includes `spLeft_963`/`RightHand_1006` |
| `the_arm_cut_includes_the_hand_geometry` | `rig.rs` | Arm cut excludes Head/Legs/Tail |
| `posed_arms_move_as_one_body` | `rig.rs` | Per-bone vertex drift < 2.0 under walk clip |
| `girl_clips_decode_with_the_measured_shapes` | `rig.rs` | 11 clips, durations, roles match manifest |
| `interpolation_modes_preserved` | `rig.rs` | STEP/CUBICSPLINE/Constant clips sampled correctly |
| `playback_rate_scales_with_scale` | `gltf.rs` | `playback_rate(4.3, 0.565) ≈ 1.0` not 4.0 |
| `joint_index_bounds_check` | `rig.rs` | All vertex `joint` < skeleton.joints.len() |
| `weighted_skinning_roundtrip` | `gltf.rs` | 4-weight vertex uploads all 4 joints + weights |
| `draw_call_offsets_match_upload` | `gltf.rs` | `first_index = alloc.first_index + prim.first_index`, `vertex_offset = alloc.vertex_offset` |
| `viewmodel_instance_count_correct` | `gltf.rs` | `viewmodel_total` = sum of per-path viewmodel counts |
| `arm_cut_share_threshold` | `rig.rs` | Share > 0.25 rejects viewmodel |

### 4.2 Integration Tests (CPU→GPU, headless, read-back)

| Test function | File | Validates |
|---------------|------|-----------|
| `upload_girl_model_readback` | `gltf.rs` | Upload → GPU read-back → vertex/index data matches CPU |
| `viewmodel_upload_separate_allocation` | `gltf.rs` | Viewmodel gets own allocation, indices relative to it |
| `palette_upload_matches_cpu` | `gltf.rs` | GPU palette buffer = CPU `compose_palette` output |
| `instance_buffer_upload` | `gltf.rs` | Instance matrices match `sync_gltf_instances` output |
| `material_buffer_upload` | `gltf.rs` | GPU materials match CPU `gltf_material_to_gpu_material` |

### 4.3 Render Tests (GPU, headless, screenshot compare)

| Test function | File | Validates |
|---------------|------|-----------|
| `viewmodel_screenshot_girl` | `gltf.rs` | Screenshot hash matches `girl.glb.expected.png` |
| `viewmodel_no_mirroring` | `gltf.rs` | Left/right hand correct, not mirrored |
| `viewmodel_arms_only` | `gltf.rs` | No torso/head/legs pixels in viewmodel pass |
| `body_screenshot_girl` | `gltf.rs` | Body pass screenshot hash |
| `animation_walk_cycle` | `gltf.rs` | 10-frame walk cycle hash sequence matches |
| `mirror_test_model` | `gltf.rs` | Symmetric model renders symmetrically |

## 6. Oracle Generation Workflow

```bash
# 1. Build test binary with render feature
cargo build -p exsolis_client --bin exsolis --features render

# 2. Run oracle generator (separate binary or test with `GENERATE_ORACLE=1`)
GENERATE_ORACLE=1 cargo test -p exsolis_client --bin exsolis \
  viewmodel_screenshot_girl -- --nocapture

# 3. Outputs written to assets/test/
#    - girl.glb.expected.png (screenshot)
#    - girl.glb.expected.json (serialized expected structs)
#    - girl.glb.expected.metrics.json (counts, bbox, etc.)

# 4. Commit oracle files to git
git add assets/test/
git commit -m "oracle: update girl.glb reference"
```

**Oracle JSON schema** (example):
```json
{
  "skeleton": { "joint_count": 82, "clip_count": 11 },
  "arm_cut": { "joint_names": [...], "vertex_count": 3456, "share": 0.181 },
  "bbox": { "min": [-0.68, -0.005, -0.44], "max": [0.68, 3.19, 2.70] },
  "uv_span": 1.19,
  "clips": [ { "index": 0, "name": "walk", "duration": 1.0, "role": "Walk", "natural_speed": 1.193 } ]
}
```

## 7. CI Integration

```yaml
# .github/workflows/gltf-tests.yml
jobs:
  gltf-unit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@nightly
      - run: cargo nextest run -p exsolis_client --lib

  gltf-integration:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@nightly
      - run: sudo apt update && sudo apt install -y libvulkan-dev xvfb
      - run: xvfb-run -a cargo nextest run -p exsolis_client --test integration

  gltf-render:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@nightly
      - run: sudo apt update && sudo apt install -y libvulkan-dev xvfb mesa-vulkan-drivers
      - run: xvfb-run -a cargo nextest run -p exsolis_client --test render
      - name: Upload screenshots on failure
        if: failure()
        - uses: actions/upload-artifact@v4
          with:
            name: render-failures
            path: target/render-failures/
```

## 10. Debugging Checklist (when exploded mesh appears)

| Check | How |
|-------|-----|
| Vertex `joint` index in bounds? | `assert!(v.joint < skeleton.joints.len())` in `posed_arms_move_as_one_body` |
| `first_index` / `vertex_offset` correct? | `draw_call_offsets_match_upload` test |
| Palette row matches skeleton joint? | `palette_upload_matches_cpu` read-back test |
| Viewmodel uses own allocation? | `viewmodel_upload_separate_allocation` test |
| Arm cut share < 0.25? | `arm_cut_share_threshold` test |
| `viewmodel_total` = sum of viewmodel counts? | `viewmodel_instance_count_correct` test |
| `T(-pivot)` NOT in model matrix? | `viewmodel_matrix` ends with translation `position - pivot`, not `* T(-pivot)` |
| Bone palette stride 256? | `PALETTE_STRIDE` = `MAX_GLTF_JOINTS` = 256 |
